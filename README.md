# 🛒 Gestor de Shopping — Java OOP

Projeto acadêmico desenvolvido em **Java** para praticar os fundamentos de **Orientação a Objetos (OOP)**, aplicados ao contexto de gerenciamento de um shopping center.

> Desenvolvido como parte da disciplina de Programação de Soluções Computacionais — UniRitter (ADS).

---

## 🎯 Conceitos Aplicados

| Módulo | Conceito |
|---|---|
| `Criacao de classes` | Encapsulamento, atributos, construtores e métodos |
| `Arrays1` | Arrays e coleções de objetos em Java |
| `Associacao Entre Classes` | Relacionamento e composição entre objetos |
| `Heranca e Polimorfismo` | Herança, sobrescrita de métodos e polimorfismo |

---

## 🏗️ Contexto do Projeto

O sistema simula o gerenciamento de um shopping, contemplando:

- Cadastro e gerenciamento de lojas
- Organização por categorias e setores
- Relacionamento entre entidades (shopping, lojas, funcionários)
- Aplicação progressiva dos pilares da OOP

---

## 🚀 Tecnologias Utilizadas

- **Java** (JDK 17+)
- **Orientação a Objetos** — Encapsulamento, Herança, Polimorfismo, Abstração

---

## ▶️ Como Executar

### Pré-requisitos

- JDK 17+
- IDE Java (IntelliJ IDEA, Eclipse ou VS Code com extensão Java)

### Execução

```bash
# Clone o repositório
git clone https://github.com/Gabriel-M19/Gestor-de-Shopping.git

# Abra na sua IDE e execute o arquivo Main.java de cada módulo
```

---

## 📚 Aprendizados

- Modelagem de sistemas orientados a objetos
- Boas práticas de organização e nomeação de classes
- Aplicação dos 4 pilares da OOP em um contexto real
- Progressão incremental de complexidade entre os módulos
